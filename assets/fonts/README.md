# PDF fonts (embedded)

Used by `@react-pdf/renderer` for invoices and consent PDFs.

- **Roboto** Regular + Bold — Apache License 2.0 (see `LICENSE-Roboto.txt`)
- Covers Latin Extended glyphs needed for BS/HR/SR: č ć š ž đ (and uppercase)

Do not switch back to Helvetica — it cannot render those characters.
